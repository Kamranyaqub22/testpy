The Lucide icons Horizon uses (lucide-static 0.460.0, ISC licence), shown in `ink` #0d1a16. In code, use them through `HzIcons` (Flutter, `lucide_icons_flutter`) with stroke width 2 and a colour from a text token or category token. The file name is the Lucide name, and the `HzIcons` name is its camelCase (for example `arrow-up-right` → `HzIcons.pay`; see Iconography in the README for the meanings). Don't add icons from other sets; if Lucide has no fitting icon, ask for one to be added to `HzIcons` first.
